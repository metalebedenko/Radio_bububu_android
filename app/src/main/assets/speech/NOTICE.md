# Происхождение данных C10

Версия: `c10-speech-data-v1`. Это пакет данных и редакторских решений; внешний код, модели, eSpeak GPL и Sokr.ru в него не включались.

Собственные проектные данные отделены в `LETTER_NAMES.project.json`: таблица 33 русских букв, девять прежних точных форм и политика побуквенного чтения. Для записей `PROJECT_*` произносимые формы заданы проектом. В `PROVENANCE.json` отдельно указано, использовалась ли внешняя статья как лексическое свидетельство и было ли чтение адаптировано из её явной фонетической подсказки. IPA и диакритики в поля `spoken` не переносились.

Для Викисловаря сохранены точные названия статей, ID ревизий, ссылки на эти ревизии и историю авторства. Источник — участники русского Викисловаря, [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Перечень атрибуции — `notices/WIKTIONARY_ATTRIBUTION.tsv`; текст лицензии — `notices/CC-BY-SA-4.0.txt`. Изменения: выбор ограниченного набора записей, редакторские классы, адаптация некоторых фонетических подсказок в обычные русские буквы без знаков ударения, отделение неоднозначных случаев. Заимствованные и адаптированные словарные данные следует сопровождать этой атрибуцией и условиями CC BY-SA 4.0. Полные статьи, примеры цитат и аудио не являются данными для включения в приложение; они остались только инертными исследовательскими свидетельствами в quarantine.

Некоторые короткие текстовые раскрытия взяты из `NVIDIA/NeMo-text-processing`, revision `ddadfb2a38d2bc6b8cc6232c4f915eb60f500688`, файл `nemo_text_processing/text_normalization/ru/data/whitelist.tsv`. [Точная исходная версия](https://raw.githubusercontent.com/NVIDIA/NeMo-text-processing/ddadfb2a38d2bc6b8cc6232c4f915eb60f500688/nemo_text_processing/text_normalization/ru/data/whitelist.tsv). Репозиторий указывает Apache 2.0; исходный текст лицензии сохранён как `notices/NEMO_LICENSE.txt`. TSV не содержит собственной copyright-шапки; проверенный корневой NOTICE отсутствовал. Это не аудит всех вложенных файлов репозитория. Изменения: только выбранные строки, явно перечисленные варианты пробелов и обязательные проектные контексты. Строки и исходные ключи указаны в `PROVENANCE.json`.

Лицензионные сведения и происхождение относятся к соответствующим внешним данным. Этот файл не объявляет новую лицензию для кода приложения или прежних собственных проектных форм. Для речевого представления Telegram используются свойства публичной Unicode Character Database 17.0: [emoji-data.txt](https://www.unicode.org/Public/17.0.0/ucd/emoji/emoji-data.txt), [UnicodeData.txt](https://www.unicode.org/Public/17.0.0/ucd/UnicodeData.txt), [DerivedCoreProperties.txt](https://www.unicode.org/Public/17.0.0/ucd/DerivedCoreProperties.txt).
